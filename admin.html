Районы обслуживания

Дальние районы обслуживаются в назначенный день месяца — адреса копятся и едут одной поездкой

Как это работает

  1. Обычный район — адреса распределяются в любой рабочий день, как обычно.
  2. Выезд раз в месяц — адреса ждут своего дня. Клиентам не предлагается никакая другая дата.
  3. В день выезда ставятся только адреса этого района: поездка не разбавляется ближними сборами.
  4. Адрес с индексом, которого нет в списке, в автоматическое распределение не попадёт. Назначить его можно вручную через переписку.

Изменение режима не трогает уже согласованные сборы — только новые распределения.

Ключи приёма

Скрипт почты присылает заявки этим ключом. Ключ виден один раз — при создании.

Подключение почты

Чтобы письма партнёра сами превращались в заявки, один раз настраивается небольшой скрипт в вашем Gmail. Он читает только письма от указанного отправителя, ничего не удаляет и не отвечает.

Эти два значения вставляются в скрипт вместе с ключом приёма. Ключ anon публичный — он уже есть в приложении; сам по себе доступа к заявкам не даёт.

После создания назначьте аккаунт: Настройки → Часы и доступ → Назначить доступ.

Скопируйте ключ сейчас — второй раз он не показывается. Если потеряете, создайте новый и замените в скрипте.
