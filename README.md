# Слой переводов — как добавлять тексты

- Русский текст в коде — это ключ. Новую подпись пиши по-русски и оборачивай: `T('Новая подпись')`.
  В шаблонных строках — `${T('кусок')}`. Разметка `admin.html` переводится сама при загрузке
  (`SubnexI18n.translateDom`): ключ — текст узла без лишних пробелов.
- Перевод добавляй в `i18n.js`, в словарь `SubnexI18n.EN`: `'Новая подпись': 'New label',`.
- Проверка: `npm run test:i18n` — покажет ключи без перевода и русские строки без `T()`.
- Массовая обёртка (после большого куска нового кода): `npm i` (нужны acorn, magic-string, parse5),
  затем `npm run i18n:wrap` — оборачивает все русские строки и собирает ключи в `_tools/keys.json`.
  Ключи без перевода видно тестом; переводы дописываются в `i18n.js` вручную.
- Телефон (`index.html`) переводится своим словарём `STR` (`t('ключ')`); язык общий —
  `localStorage.subnex_lang`.
